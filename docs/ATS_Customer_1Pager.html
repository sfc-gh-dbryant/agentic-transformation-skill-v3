Existing Data Is Protected
🔍

Dry Run — Default ON

Every pipeline run generates and logs DDL but executes nothing. You review every statement before a single table is touched.

🛡️

Overwrite Protection — Default OFF

If a target table already has rows, the Executor skips it, logs it, and continues. Existing data is never overwritten unless you explicitly permit it.

🌾

Brownfield Mode

For environments with existing Silver tables, Brownfield Mode skips them entirely and processes only the gaps. Existing tables logged as EXISTING, never touched.

A first run against any environment — greenfield or brownfield — produces zero side effects until your team has reviewed and approved the proposed DDL.
